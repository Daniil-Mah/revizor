План ан 20.10

В назначении может быть несколько людей на 1 объект

1) титульный лист
2) задание
3) оглавлвние 
4) введение
5) теоретическая часть 
1.1 техническая часть на разработку программного продукта
1.2 организация пользовательского ввода\вывода
1.3 опсиание предметной области
